How this client-server application works

  1. The user interacts with this webpage, which is the presentation layer (client).
  2. The client sends HTTP requests to the Flask server.
  3. The server processes requests and communicates with the database when database operations are implemented.
  4. The server returns a response, which the client displays.

Current scope: This interface tests the Flask routes described in the setup guide. It does not create, edit, or delete inventory or orders until those API operations are implemented on the backend.
